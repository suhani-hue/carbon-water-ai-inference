# Failure Boundaries for Carbon- and Water-Aware AI Inference

**Researcher:** Suhani Soni  
**School:** Children's Hope India Girls School  
**Location:** Bhopal, Madhya Pradesh, India  
**Project status:** Protocol development — no final experimental results yet

## Research question

Under what combinations of latency constraints, regional capacity, forecast error, workload intensity, and water-accounting assumptions does carbon- and water-aware routing of geo-distributed AI-inference requests improve—or worsen—the carbon–water–service-quality trade-off?

## Scope

This project models the operational stage of AI inference serving. It excludes embodied carbon, embodied water, upstream supply-chain impacts, model training, and full life-cycle assessment.

## Reproducibility

The repository contains the protocol, code, configuration files, raw-data documentation, processed data, experiment logs, analysis, figures, and manuscript. Results will not be added until experiments are actually completed.
